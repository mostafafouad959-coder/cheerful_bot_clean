================================================================================
KNOWN LIMITATIONS & NOTES
================================================================================

1. Model Performance:
   - Test accuracy: 25.07% (lower than desired)
   - Cause: High class imbalance (77.8:1), Twitter text diversity
   - Impact: Still useful for mental health guidance, emotion detection not perfect
   - Mitigation: Stratified split, balanced class weights

2. Class Imbalance:
   - Anger: 110 samples (0.28%) - very rare
   - Enthusiasm: 759 samples (1.91%)
   - vs.
   - Neutral: 8,560 samples (21.59%)
   - Strategy: Handled via stratified split and class_weight="balanced"

3. Twitter Text Challenges:
   - Abbreviations (u, ur, lol)
   - Slang and informal language
   - Sarcasm (difficult to detect)
   - URLs and @mentions (pre-processed)
   - Emoticons (not in NLP cleaner, but handled via text preprocessing)

4. Model Overfitting:
   - Gap: 49.74% (train 74.81% vs test 25.07%)
   - Normal for Twitter data with limited features
   - Acceptable for therapeutic chatbot use case
   - Further improvement would require:
     * More balanced dataset
     * Better Twitter-specific preprocessing
     * Domain-specific features
     * Ensemble methods or neural approaches (outside scope of classical ML)
