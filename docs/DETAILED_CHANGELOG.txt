FILE 1: migrate_dataset.py [NEW FILE]
================================================================================

File Name: migrate_dataset.py
Location: /cheerful_bot/
Purpose: Automatic dataset migration and cleaning script
Size: ~4.5 KB
Status: NEW

What the file does:
───────────────────
1. Loads Kaggle emotion dataset (tweet_emotions.csv)
2. Renames columns (sentiment→emotion, content→text)
3. Removes Twitter-specific noise (@mentions, URLs, RT)
4. Validates data (missing values, duplicates, empty rows)
5. Maps 'worry' emotion to 'anxiety' for consistency
6. Selects the best 12 emotions for mental health chatbot
7. Saves cleaned dataset as emotion_dataset_kaggle.csv

Key Functions:
───────────────
- clean_twitter_noise(text): Removes @mentions, URLs, RT, HTML entities
- Main script: 6-step process with detailed logging

Output:
───────
File: data/emotion_dataset_kaggle.csv
Format: CSV with columns: text, emotion
Rows: 39,653 (cleaned from 40,000)
Emotions: 12

Run Command:
────────────
$ python3 migrate_dataset.py
